# 🚌 Smart City Transport

## 📌 Overview

Smart City Transport is an AI-powered transportation management application developed using Flutter and Dart. The application helps commuters access transport information, find routes, view schedules, and interact with an intelligent AI assistant for transportation-related queries.

The project aims to improve urban mobility by providing a centralized platform for commuters and administrators while leveraging AI to enhance user experience.

---

## ✨ Features

### 👤 User Authentication

* User Registration
* Secure Login System
* Role-Based Access

### 🚌 Transport Management

* Route Information
* Transport Schedules
* Fare Details
* Commuter Services

### 🤖 AI Transport Assistant

* Powered by Gemini AI
* Route Guidance
* Travel Assistance

* Intelligent User Interaction

### 👨‍💼 Admin Module

* Administrative Controls

### 💾 Database Integration

### 🎨 User Interface

* Modern Flutter UI
* Responsive Design
* Multi-Screen Navigation

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/TarunKumarShukla/Smart_City_Transport.git
```

### Navigate to Project

```bash
cd Smart_City_Transport
```

### Install Dependencies

```bash
flutter pub get
```

### Run Application

```bash
flutter run
```
