# 🚌 Smart City Transport

## 📌 Overview

Smart City Transport is an AI-powered transportation management application developed using Flutter and Dart. The application helps commuters access transport information, find routes, view schedules, and interact with an intelligent AI assistant for transportation-related queries.

The project aims to improve urban mobility by providing a centralized platform for commuters and administrators while leveraging AI to enhance user experience.

## ⚙️ Installation

### Clone Repository

```bash

```

### Navigate to Project

```bash
cd Smart_City_Transport
```

### Install Dependencies

```bash
flutter pub get
```

### Run Application

```bash
flutter run
```
